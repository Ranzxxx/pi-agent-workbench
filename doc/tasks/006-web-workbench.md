## 验收标准

- [ ] 一个开发命令启动 API 和 Web，默认绑定回环地址，API Key 只保留在服务端。
- [ ] API 支持创建/查询/取消/重试及产物访问；忙碌时明确返回，默认最多一个运行。
- [ ] SSE 发送版本化事件，ID 单调；进程存活期间可按最后 ID 补发，缓冲丢失明确返回重置指示。
- [ ] 浏览器断线不取消 Agent，主动取消才发送取消请求；幂等取消和终态竞争有测试。
- [ ] 重试使用新 runId，关联旧任务，事件不能串线。
- [ ] 页面包含输入、状态、工具时间线、报告和证据，不解析终端日志判断状态。
- [ ] 报告渲染禁止任意 HTML/危险链接；产物接口限制在任务目录，防止路径逃逸。
- [ ] fake 模式下浏览器验证正常、失败、取消、重连和产物查看，无真实模型费用。
- [ ] 明确说明内存状态在进程重启后不可恢复；不暗示已实现 v0.2。
- [ ] 根 README 启动路径与实际一致，留下演示步骤和限制。
