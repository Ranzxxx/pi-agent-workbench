## 背景

## 目标

建立一个隔离的 TypeScript 技术验证程序，确认以下能力的真实 API 和行为：

1. 创建并释放 PI Agent 会话。
2. 注册一个只读自定义工具并获得结构化结果。
3. 订阅并记录消息、工具调用、完成和错误事件。
4. 验证取消、超时和失败传播行为。
5. 形成 PI SDK 适配层的接口建议和已知限制。

## 非目标
