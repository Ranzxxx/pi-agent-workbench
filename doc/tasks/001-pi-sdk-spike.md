## 背景

项目需要先验证 PI SDK 是否能够支撑 Web Agent Worker 的核心生命周期，再建立正式工程骨架。本任务是 v0.1 前置实验。实现已合并，复审发现原验收断言和配置隔离不足，由 TASK-002 修复；保留原提交历史，不将补强结果追溯为原始验证。

## 目标

建立一个隔离的 TypeScript 技术验证程序，确认以下能力的真实 API 和行为：

1. 创建并释放 PI Agent 会话。
2. 注册一个只读自定义工具并获得结构化结果。
3. 订阅并记录消息、工具调用、完成和错误事件。
4. 验证取消、超时和失败传播行为。
5. 形成 PI SDK 适配层的接口建议和已知限制。

## 非目标

- 不搭建 Next.js、Fastify 或正式 monorepo。
- 不实现 GitHub 技术尽调流程。
- 不实现数据库、任务恢复、子 Agent、沙箱或长期记忆。
- 不修改仓库根目录 `pi/` 中的 PI 源码。
- 不默认调用付费模型。
