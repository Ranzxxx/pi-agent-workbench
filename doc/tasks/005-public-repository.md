## 验收标准

- [ ] URL 严格解析为 GitHub owner/repo/ref，拒绝凭据 URL、任意主机和危险重定向目标。
- [ ] ref 先解析 SHA，再按该 SHA 获取归档；输出/缓存使用实际 SHA，不能用可变分支作版本标识。
- [ ] 流式下载/解包限制在过程中生效；拒绝路径穿越、链接、特殊文件、过多文件与超大展开内容。
- [ ] 网络、限流、仓库不存在和获取超时都有结构化失败，事件不泄露 Token。
- [ ] 固定第一个公开小仓库 SHA 与许可元数据，维护人工必答事实清单。
- [ ] faux provider 下端到端流程可离线回归；下载层使用可控 HTTP fixture。
- [ ] 每次运行强制执行时长、调用/工具/Token预算；超限后不开始新调用，结果说明原因。
- [ ] 在线评测前明确模型、价格表、Token 和成本上限并获得授权；至少保存机器可读指标与人工证据支持评分。
- [ ] 真正的仓库→报告展示通过；若未获在线授权，不把真实模型验收勾选为通过。
